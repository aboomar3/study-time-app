# 📚 تطبيق مؤقت الدراسة والمهام

تطبيق ويب عصري وجميل لإدارة جلسات الدراسة والمهام باستخدام تقنية Pomodoro.

## ✨ المميزات

- ⏱️ **مؤقت Pomodoro قابل للتخصيص**
  - جلسة دراسة: 25 دقيقة
  - راحة قصيرة: 5 دقائق
  - راحة طويلة: 15 دقيقة

- 📋 **إدارة المهام المتقدمة**
  - إضافة ومسح المهام بسهولة
  - تحديد المهام كمنجزة
  - عد المهام المكتملة

- 🎨 **تصميم عصري وجميل**
  - واجهة مستخدم متجاوبة (Responsive)
  - تدرجات لونية جميلة
  - حركات انتقالية سلسة
  - دعم اللغة العربية (RTL)

- 💾 **حفظ البيانات محلياً**
  - تخزين المهام والإحصائيات
  - استرجاع البيانات تلقائياً

- 🔔 **إشعارات وتنبيهات**
  - تنبيهات صوتية عند إنهاء الجلسة
  - رسائل تحفيزية

## 🎯 كيفية الاستخدام

### استخدام المؤقت
1. اختر نمط الدراسة (دراسة / راحة قصيرة / راحة طويلة)
2. انقر على **"ابدأ"** لبدء المؤقت
3. استخدم **"إيقاف مؤقت"** للإيقاف المؤقت
4. انقر على **"إعادة تعيين"** لإعادة تعيين المؤقت

### إدارة المهام
1. اكتب المهمة في حقل الإدخال
2. انقر على **"أضف"** أو اضغط Enter
3. اختر المهام المكتملة بالنقر على الخانة
4. احذف المهام بالنقر على رمز X
